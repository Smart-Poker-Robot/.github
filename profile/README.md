## About

Smart Poker Robot builds AI poker software and poker platform technology. Our work sits in two connected areas:

- **AI poker tools** for studying poker strategy, modelling decisions under incomplete information, and practicing in training environments.
- **Platform and API solutions** for businesses that build or operate poker products.

Poker is a game of probability, optimization and opponent modelling. We build software that treats it that way: as a decision-making problem that can be analysed, configured, tested and improved.

Effective poker AI is more than a fixed list of rules. It combines real-time context, probabilistic decision-making, configurable behaviour and dependable infrastructure. We write about it, build it, and want it to be understood clearly, including its limits.

## Responsible use

> **Please read this before using any of our software.**
>
> **AI poker tools.** Our AI poker tools are intended for education, research, strategy study and practice, in free-to-play games and training environments. We do not condone cheating in any form, and our tools are not intended for use on real-money poker platforms.
